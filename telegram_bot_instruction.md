# Создание Telegram-бота и получение Chat ID

Инструкция по созданию Telegram-бота и получению параметров для отправки уведомлений в личный чат, группу или канал.

## Создание бота

1. Откройте Telegram.
2. Найдите бота `@BotFather`.
3. Отправьте команду:

   ```text
   /newbot
   ```

4. Укажите название бота.
5. Укажите username бота — имя, по которому его можно будет найти в Telegram.
6. Сохраните токен из ответного сообщения BotFather.

## Получение токена

После создания бота BotFather отправит сообщение с токеном.

В дальнейших примерах токен обозначается как `BOT_TOKEN`.

```text
BOT_TOKEN=<токен, полученный от BotFather>
```

## Подготовка чата

### Личный чат

Откройте созданного бота и отправьте команду:

```text
/start
```

### Группа или канал

1. Создайте группу или канал, если они ещё не созданы.
2. Добавьте созданного бота.

## Получение Chat ID

`CHAT_ID` — идентификатор чата, в который бот будет отправлять сообщения.

### Способ 1. Через Telegram Bot API

После отправки сообщения боту откройте в браузере:

```text
[https://api.telegram.org/bot](https://api.telegram.org/bot)<BOT_TOKEN>/getUpdates
```

Замените `<BOT_TOKEN>` на токен, полученный от BotFather.
Угловые скобки в итоговом адресе не нужны.

В ответе найдите объект `chat` и значение поля `id`.

Пример фрагмента ответа:

```json
{
  "chat": {
    "id": 123456789
  }
}
```

В этом примере:

```text
CHAT_ID=123456789
```

> Отправка `/start` в личном чате позволяет получить идентификатор
> этого личного чата, а не идентификатор группы или канала.
> Для группы или канала нужен идентификатор соответствующего чата.

### Способ 2. Через вспомогательных ботов

В исходной инструкции перечислены следующие боты:

| Бот | Использование |
|---|---|
| `@getmyid_bot` | Получение ID личного чата: отправьте `/start` |
| `@my_cyber_eye_bot` | Получение ID канала: перешлите сообщение из канала |
| `@RawDataBot` | Просмотр данных сообщения |
| `@chatid_echo_bot` | Получение идентификатора чата через эхо-бота |

### Примеры идентификаторов

| Тип чата | Пример Chat ID |
|---|---|
| Личный чат | `123456789` |
| Группа или канал | `-1001234567890` |

Значения приведены только для примера. Используйте идентификатор своего чата.

## Результат

После выполнения инструкции у вас будут:

- Telegram-бот;
- `BOT_TOKEN` — токен созданного бота;
- `CHAT_ID` — идентификатор чата для уведомлений.

Пример записи параметров:

```text
BOT_TOKEN=<токен вашего бота>
CHAT_ID=<идентификатор нужного чата>
```

Эта инструкция описывает создание бота и получение параметров.
Код отправки сообщений в неё не входит.
